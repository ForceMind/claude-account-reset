01 / 边界

日常只读，维护前先审阅。

按需清理

账号与认证状态

已知 OAuth 字段、Cookie、上次账号提示、同步归属，以及配置恢复日志。扩展模式还清理已知账号功能缓存和遥测。

保护并校验

对话与本地工作

已知会话目录、附件和文件历史校验前后一致；保留 Local Storage 中的会话索引、草稿、预设与未知记录。

这不是账号迁移或全盘痕迹擦除。保留的会话可能含账号引用；新账号能否显示旧历史取决于 Claude。未知认证格式、IndexedDB 与 Session Storage 不做盲目删除。

02 / 在 Mac 上运行

也可以在终端自行运行。

下载安装脚本 ↓
  1. 01

    准备环境，退出 Claude

    需要 Node.js 22+。退出 Claude Desktop 和 Claude Code。下载脚本后先阅读内容；不需要管理员权限。

  2. 02

    运行安装脚本

    在脚本所在目录打开终端。脚本下载并校验工具包、安装锁定依赖，不执行清理。

    bash install.sh

    安装后按终端提示进入新建的版本目录。

  3. 03

    生成计划，审阅后单独执行

    ID 来自本地预览。未指定日期时不启用时间保护；格式或时间未知的候选项会在启用保护时跳过。更多排除和基线选项见 README。

    node bin/reset.mjs --plan-out reset.plan.json

    先阅读上一步保存的计划。 范围正确后，再单独复制执行命令；不能在执行时追加选择或删除参数。

    node bin/reset.mjs --execute reset.plan.json --yes

    默认只读。展示已知字段的处理计划，检查后删除临时数据库副本。

    钥匙串密钥用于应用加密，并非账号密码。删除可能使其他 Claude profile 的加密凭据失效，需要重新授权。

03 / 恢复本地历史

列表不见了，正文可能还在。

新增索引 · 保留原件

恢复 Code 对话

先登录目标账号并进入 Code，再退出 Claude。工具匹配已有索引与本地正文，备份目标目录后仅新增缺失记录。已有记录跳过，归档状态保留；工作目录缺失会单独报告。

兼容性边界

保护近期续聊与多份历史

用明确的会话 ID、排除名单、日期时区和基线限定范围。长短快照分别保留可见内容；真正分叉和变更的 CLI 关联默认保护。新增会话不会被旧计划自动纳入。

当前恢复支持本地 Code 索引，不自动迁移 Cowork 或云端聊天。恢复会话使用手动权限、远程控制关闭。请将 recovery-backups 和报告保留在本机，不上传。

04 / 新账号接手

留下可见历史，清理已知旧思考。

独立 handoff 命令先预览，再备份和改写正文。只移除已识别的 thinking 块，用户消息、可见回答与工具记录不变，并生成逐会话 Markdown 接手文档。

会修改共享正文，其他 profile 也可能受影响。接手文档是可见原文整理，不是自动确认的任务摘要。它不转换内部思考、不伪造签名，也不能保证账号匿名或所有模型兼容。Cowork 暂未支持。

node bin/handoff.mjs --plan-out handoff.plan.json --discard-backup

上面只生成计划。执行计划后，全部本地检查成功且无未解决项时才删除本批次备份；主动排除和近期活动保护不算失败。文档保留在本机。

05 / 理解每一步

知道为什么删，也知道留下什么。

计划生成后还能改参数或继续聊吗？

执行范围已经保存在计划中。相关文件、账号、组织或会话集合变化，会使计划过期，需重新预览。执行参数不能扩展原计划范围。备份、空间和进程检查失败时停止。

如何检查备份和恢复？

使用 node bin/backup.mjs --inspect 批次目录 检查，生成独立恢复计划后再执行。恢复前保存当前状态，遇到新内容判为冲突，避免覆盖。查看安全与恢复契约。

为什么要清理配置恢复日志？

config.json.journal 是配置写入和恢复使用的日志。只改主配置可能让旧状态恢复。工具配套删除日志，并回读主配置验证目标字段。

为什么 Local Storage 不能整个删除？

它混合存放账号提示、同步身份、界面设置、会话索引和草稿。工具仅匹配已知来源与键名，校验其他记录字节不变，再压缩失效旧记录。数据库压缩不等于安全擦除。

和 MultiClaude 的隔离原理有什么关系？

MultiClaude 通过独立数据目录分开账号。这提示检查不应限于默认 Claude 目录。本工具检查相邻 Claude-* 目录，但不会把整个目录视为凭据，也不依赖安装 MultiClaude。

“不能使用另一个组织的 thinking”是没清干净吗？

这指向保留历史中的账号绑定推理块，不能证明旧登录仍有效。恢复命令只统计并保留 thinking；独立 handoff 命令可在备份后移除已知思考块，但不重签。Claude 可能跳过它们，重新推理。阅读官方说明。

数据会上传吗？

网页没有上传入口、第三方统计或外部脚本。安装时访问下载站与 npm；清理工具本身不发送网络请求。本地报告可能包含路径和字段名，分享前请检查。

清理失败或版本变化怎么办？

遇到运行中的 Claude、符号链接、损坏配置或数据库错误时停止。跨文件清理不具备全局事务性，已完成的删除不会自动回滚。规则依据 Desktop 4.29.0，不承诺其他版本完全覆盖；未知字段保留。
