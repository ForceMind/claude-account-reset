## v0.6.0 · macOS 桌面预览版

在 Mac 本地管理 Code 会话与配置，普通使用无需安装 Node.js 或输入命令。

- 会话列表、标题与项目筛选、分页预览、工具内收藏和备注。
- 按需识别相同副本、前缀快照与分叉；不自动合并或删除历史。
- 只读环境概览，显示配置来源、冲突和未知项，隐藏凭据值与 URL 密码。
- 导出完整可见历史为 Markdown；备份正文原字节及 thinking，附 SHA-256 清单。
- 保留现有清理、备份验证与文件恢复流程，兼容经验证的 v0.5.0 维护备份。

### 下载与验证

提供 Apple Silicon（arm64）的 DMG、ZIP，及可选的 AI/CLI 工具包。下载同页的 `SHA256SUMS`，核对文件完整性。

本版有 ad-hoc 签名，未完成 Developer ID 分发签名和公证，可能出现系统安全提示。Intel、Windows、账号切换、云端聊天和未知 Cowork 格式尚未支持。

验证使用合成资料，包含原生桌面流程、包内后台/原生模块、导出备份回读和本地测试；没有使用用户真实账号或会话，没有验证真实 Claude 续聊。网站浏览器验收未执行。

会话资料备份不含项目、外部附件或云端资产，不自动导入 Claude。本工具不承诺解除账号限制或设备匿名。只分发通用源码、安装包与公共校验元数据，不包含用户会话、备份、密钥或机器报告。
