# macOS 桌面客户端 v0.6.0

本批次在独立 `desktop-gui` worktree 开发，不包含迁移项目代码。应用启动不自动扫描；所有数据操作都由用户选择资料目录后触发。默认入口为只读会话管理，原有检查/清理及本客户端维护批次的文件恢复继续保留。账号切换、Windows、改写 thinking 和写入型旧索引恢复的图形入口不在本版范围。

## 会话与环境

“会话”读取 Desktop Code 索引和 Code 主会话正文，按明确 CLI 关联分组。缺少关联时不猜测；同一 Desktop 标识关联不同 CLI ID 时分别保留。重复正文、前缀快照和分叉需要按需分析，不自动合并或删除。索引损坏、正文缺失、工作目录失效会显示；未知 Cowork/云端格式和独立子代理不作为主会话导入。

列表每页 40 条；支持标题/项目搜索、项目与归档/异常/收藏筛选。预览按游标分页、限制单页文本，长记录明确标为截短；thinking 只显示计数，不显示内容、不改写原件。来源在读取后变化时旧游标失效，需重新读取。列表元数据可能过期，不把文件修改时间当作用户最后发言时间。收藏和备注只保存在本工具私有存储中，不能改写 Claude 的标题或归档标记。

环境概览只读取已授权的 Desktop、Code 与可选项目配置；不同项目分别展示，不能互相覆盖。展示连接与模型候选、来源差异、MCP 名称及凭据是否配置；URL 只显示协议、主机和端口，凭据和 helper 命令不进入界面。MCP、helper、网络和模型请求均不执行。托管策略、其他进程环境、在线登录与真实请求路径未验证；缺少 Base URL 不等于已确认官方连接。CC Switch 私有数据库不读取、不修改，只展示 Claude 文件中实际读到的设置。

## 文档导出与会话资料备份

选择会话后先核对数量和副本范围，再选择独立保存位置。每个副本分别保存，分叉不会丢弃。Markdown 导出完整可见文本及工具记录，使用安全文本围栏，不含 thinking 和二进制附件载荷；不是 AI 推断的任务总结。资料备份保存正文原字节（包括 thinking）与白名单关联信息，不复制账号配置、待执行动作或远程连接授权。

输出创建新目录，不覆盖现有文件；源文件指纹重新校验，暂存输出验证完成后才公布结果。取消、编码错误或源数据变化不会发布成功的不完整结果。备份默认保留，附正文与关联信息的 SHA-256 清单；项目、外部附件和云端资产不包含在内，缺失记录会随 manifest 列出。本版没有把这种资料备份直接导入或替换 Claude 的入口，跨电脑迁移由独立项目负责。

“备份与恢复”同时提供会话导出目录入口和原有维护批次的恢复流程，二者用途明确区分。v0.5.0 维护批次经原有范围/内容校验后仍可恢复；旧执行计划需重新检查，不自动沿用授权。

普通用户双击应用，点击“识别本机资料”或选择文件夹，明确勾选资料和额外范围，然后生成只读检查与计划。计划不显示凭据或正文，明确显示文件、字段、保护范围、备份空间和钥匙串影响。确认按钮打开原生确认窗口，返回审阅为默认选项。后台始终保留备份，界面不提供备份删除选项。

应用启动本身不扫描 Claude 资料。只读发现可提示进程占用；生成计划、实际写入和恢复仍要求 Claude Desktop/CLI 退出。取消在安全检查边界生效，不能撤销已经完成的写入；部分停止会留下日志和备份，不能把停止理解成全局回滚。恢复前检查冲突，先备份当前状态；恢复旧配置可能带回旧凭据。文件备份不能恢复已删除的共享钥匙串项。

## 开发与测试

界面为 TypeScript、本地 HTML/CSS，主进程通过严格白名单 IPC 调用独立 utility process。界面禁用 Node、启用沙箱与上下文隔离，阻止远程内容、外部导航、新窗口和权限请求。只有原生文件夹选择器能够增加手动资料授权，执行范围使用后台保存的计划 ID，界面不能提供任意执行路径或脚本。原始 Node 核心测试继续保留。

- `npm run desktop:demo`：独立合成资料演示，不访问真实 Claude home 或系统钥匙串。演示启动生成全新资料，前一次演示备份不会出现在新一次列表中。
- `npm run desktop:start`：正常启动，仍需用户点击才能发现资料。
- `npm run desktop:make`：构建本机架构的 app、ZIP 与 DMG。原生 LevelDB 依赖随 Electron 重建、解包并随应用分发；用户无需安装 Node 或运行脚本。
- `npm test`：包含合成资料的端到端服务流程、变更后拒绝执行、冲突恢复、损坏备份、取消、目录越界及不支持平台检查。

演示入口由本机启动参数 `--demo` 控制，只能访问新生成的合成 home；它禁止手动选择其他资料和钥匙串操作。测试用此入口启动真实客户端，不能用真实用户账号代替样本。

## 本地资料和能力边界

正常使用的计划、报告、备份保存在 Electron 的本应用 userData 下 `maintenance/`，不使用原仓库相对目录，也不自动导入旧版脚本备份。个人计划和备份不进入安装包或 Git。默认保留会话、thinking、身份字段、共享钥匙串和所有备份。Windows 本批次不开放操作，不把打包成功当作平台支持。macOS arm64 与 x64 需要分别构建并验证；只对实际验证过的架构作验收声明。

本批次应用有 ad-hoc 签名，没有 Developer ID 分发签名和公证，不承诺下载后无 Gatekeeper 提示。不开启自动更新、上传或遥测。公开发布和官网切换待可审阅包验收后确认。
