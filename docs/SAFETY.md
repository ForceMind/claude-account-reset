# v0.6.0 安全执行契约

本页说明修改原件的维护执行器。图形会话浏览与环境概览只读来源，不要求先生成清理计划；收藏备注、独立导出和会话资料备份见 [桌面客户端](DESKTOP.md)。v0.5.0 的维护备份仍需通过原有内容和范围校验后才能恢复，不代表旧执行计划可直接使用。

## 计划是范围，不是可执行文件

生成计划读取目标，记录固定的 profile / Code 目录、账号/组织、会话选择、输入文件集合与哈希、权限、处理规则和空间预算。保存后权限为0600。原始配置值、token和正文不写入计划，但路径、UUID和标题仍私有。

执行时按允许的选项重新运行发现和规则计算，与保存计划比较；不会直接照着计划中某个路径 unlink。未知选项、错误版本、修改过的计划、账号/组织变化、源文件变化或新文件都会拒绝执行。计划摘要不是密码学签名；应从自己可信的私有文件执行，不能把陌生人提供的计划视为授权。

## 备份与空间

每次批次建立独立目录。原始文件逐个复制后回读SHA-256和目录结构，原权限记录在journal中，备份本身限制为目录0700/文件0600。任何备份失败都会在实际目标写入前停止。

空间预算按文件系统分组，计入原件备份、暂存结果、文档和目标上的原子替换临时文件，并保留余量。它是执行前检查，不是磁盘空间预留；其他程序仍可能在检查后消耗空间，失败会保留日志和备份。

## 写入与验证

JSON变更、正文转换、索引和文档先在暂存区生成，校验内容后再安装。LevelDB在暂存副本中删除允许键并校验其余键值，然后替换数据目录。新索引独占创建，已有文件不会被覆盖。替换和恢复均记录具体条目的前后状态。

开始实际写入前，再检查进程、源状态与计划。最终比较完整保护集合，只允许计划内路径按已验证结果变化。日志与备份用于诊断和显式恢复，不承诺跨文件全局事务或断电自动回滚。

共享钥匙串删除排在最后，但仍是不可由文件备份恢复的独立行为。查不到与无权限明确区分；不导出密钥、不注入应用、不修改访问组。

## 恢复

`backup --inspect` 检查备份。`--restore ... --plan-out ...` 生成新的恢复计划。恢复前再次检查原journal和payload哈希，以及当前目标是否仍匹配操作后的状态；有新内容就判冲突。恢复也先保存当前版本并校验，再恢复所选条目。

恢复范围必须来自原操作的已知路径规则，payload编号不能任意跳转路径。恢复原始配置可能带回旧token，恢复正文可能带回thinking；请先审阅。没有强行覆盖新数据的参数。

## 进程与平台边界

检查常见Claude Desktop/CLI进程名、bundle路径和调用者父进程链；无法确定状态则停止。检查不打印命令行参数。进程检测不是操作系统级全局锁，包装器、其他程序或恶意竞争仍可能绕开观察，所以操作期间应保持应用关闭。

本版只执行macOS规则。浏览器、服务端登记、底层设备密钥和未知凭据格式不因已知目标检查成功而被推断为空。
